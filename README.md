# lakehouse_hidrovia_Paraguai-Parana
Projeto para monitoramento de níveis fluviais das estações Assunción e Ladário da Hidrovia do Rio Paraguai. O monitoramento dessas estações é crítico para a logistica e transporte de commodities, segurança da navegação e estudos de impacto ambiental no Pantanal e na Bacia do Prata.
